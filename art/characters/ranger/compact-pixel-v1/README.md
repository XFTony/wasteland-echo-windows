# 巡线者：紧凑像素主角形象 v1

日期：2026-10-22。当前工作只制作一名主角的静态形象。

## 方向

按用户要求，停止最新高精细成人比例人物及其动作路线，转向参考《元气骑士》游戏内人物的比例、轮廓和简洁色块。巡线者保留沙色兜帽、深色面罩、橙色护目镜与围巾、棕色行装及小手枪作为自身识别特征。

本版强调大头短身、短外套、紧凑手脚、容易辨认的眼部与围巾，以及适合小尺寸观看的像素轮廓。绘制一张静态持枪形象，先评审人物本身，再决定后续动作规格。

## 文件

- [人物透明PNG](./ranger-compact-v1.png)：内置ImageGen生成原图，保留原始透明通道。
- [大小与背景对照](./review.html)：放大图和约72px可见人物高度的深浅背景对照，直接用浏览器打开。
- [完整生成提示词](./prompt.txt)：旧人物仅提供身份与颜色参考，明确重做比例和绘画语言。
- `metadata.json`：尺寸、透明度、哈希、来源及当前状态。

身份参考：`art/animation/ranger/pixel-lookdev/ranger-pixel-sidearm-v1.png`。风格观察参考《元气骑士》游戏内角色示例：[骑士图鉴](https://www.te5.com/yxrb/897775.html)、[游侠游戏内界面](https://m.gao7.com/news/1134283.shtm)。参考图未复制为本项目素材。

## 当前边界

这是一张静态形象方向图，`visualApproved=false`、`runtimeIntegrated=false`。生成原图尚未整理为固定原生像素网格或限制色板；本轮不把生成分辨率视为原生像素密度。手枪仍在画面中。

旧成人比例图和动画试验保留为历史资料，停止作为当前制作目标。后续先依据这张形象的评审调整比例、轮廓及细节，再确定原生像素规格与动作范围。
