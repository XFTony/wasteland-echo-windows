# 战地工坊素材包 v2

本工作包用于原生Godot当前开发线：6种实体卡面、42张独立改件插图、13件独立枪体（9件细化＋4件新武器）、8类敌人的四帧倒地图集，以及5段原创短音效。

- `sources/`：7张内置image_gen生成原稿，保留真正Alpha；不是代码绘制的替代图。
- `references/enemies.png`：从项目已有八类敌人提取的姿态参考，仅用于保持形象一致，没有复制竞品素材。
- `prompts.json`：内置工具、原图角色与完整提示词。
- `design.json`：4件新武器的初始设计、握点、价格、反馈与运行图路径；不是旧16武器的覆盖数据。
- `manifest.json`：74项运行文件、原图关系、字节数与SHA；视觉生成素材采用适用服务条款记录，不标为第三方CC0。
- `audio/`、`audio-manifest.json`：5段项目原创音效及SHA。不存在从参考游戏拆出的采样。

活动图在`godot/assets/{ui,weapons,actors}/fieldcraft-v2`，声音在`godot/assets/audio/fieldcraft-v2`。卡面文字由Godot绘制，枪体不包含手和袖口，死亡贴图不包含碰撞或掉落信息。

制作顺序：`prepare-fieldcraft-content.mjs`仅首次写设计（重复必须显式`--overwrite`）；`install_fieldcraft_content.gd`写原生Resource，重复默认保留人工修改；`prepare_fieldcraft_art.gd`只裁切/透明边界/最近邻缩放，不重新创作图案；之后运行Godot导入与原生检查。后期编辑Resource时不要反复重应用工作包。

手部贴合使用`calibrate_fieldcraft_grips.gd`：默认只读测量，显式`--apply`才按实际枪体Alpha轮廓移动对应手/袖口组合。当前仅修正战镰两处间隙，其他武器不移动；不改变枪口、瞄准、碰撞和武器数值。原生回归另验证13件枪体的手掌接触，重新安装设计后须复核这一项。

注意生成原稿的透明边缘可能有极低Alpha散点。细长武器使用0.2的Alpha边界估计，防止空白挤小枪体；不因此移除枪体中有效的半透明像素。死亡帧按源图实际行带划分、按原敌人身体高度统一缩放，避免固定网格边界切掉头部或四帧大小跳变。

整包69张运行图的RGBA像素数据合计6,919,488字节（约6.60MiB）；这不是整机/GPU内存占用，也不是启动时间实测。图按需解码并共享缓存，尸体最多40个、短命中簇最多112个，暂停跟随模拟时间冻结。完整效果与本人审美验收以实际窗口为准。
