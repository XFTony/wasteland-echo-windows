## 二维制作路线

可以完全使用二维制作，不要求继续 Blender 精细建模：

1. 依据真实游戏尺寸选定低分辨率画布、像素密度、受控调色板和脚底锚点；手工整理轮廓和关键明暗块。
2. 先设计巡线者默认服饰与起始手枪的跑步、侧步、后退、站立瞄准和一次射击关键姿势；握点、身体朝向和落脚一起审看。
3. 同一角色绘制连续帧，整理像素簇与透明边缘；头身比例、衣物、枪械和光源在动作之间保持一致。
4. 按武器持握家族规划上身、枪械与装备层；分层不应以不自然的腰部扭转或手臂拼接为代价。
5. 导出紧凑图集，接入真实位移驱动的步相、停步与转向；保持现有游戏数值、碰撞和存档。

Blender 可以保留作姿势、透视或骨架参考，只有能减少制作成本时才使用。生成多张相似图片也不能替代身份一致、接触可靠的连续动作。
