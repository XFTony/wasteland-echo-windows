## 整合方式

从最新已验证开发线建立`codex/repository-integration`，经PR进入main。主线受保护并要求线性历史，因此使用squash；完整原始73次迭代通过不可移动的归档标签保留。不得强推、重写旧发布标签或绕过检查。

以最新分支作为累积实现一次整合，避免将同一批改动逐分支重复合入。旧草稿PR #3的内容已在累积实现中，整合成功后关闭并注明替代关系；随后按新鲜远端头SHA核对清理12个已包含分支，以及本轮整合分支。若任何分支在执行中产生新提交，则保留并重新审查，不按旧清单强行删除。

本轮检查入口包括`npm run check`、十套原生回归、精选图片SHA比对、Markdown本地链接核对、主页实际浏览器渲染。工作流和受保护分支合并结果以对应GitHub PR／Actions记录为准。
