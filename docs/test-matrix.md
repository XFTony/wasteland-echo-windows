## 自动验收项

- 键盘、鼠标和手柄统一写入同一输入帧；
- 输入帧会限制移动范围并过滤非有限数；
- 手柄使用径向死区，断线后下一帧清除移动与射击；
- A、B、Menu 与方向导航使用边沿或受控重复，不会每帧触发；
- 菜单焦点不依赖 DOM，Canvas 按钮可用键盘和手柄操作；
- 内容表启动校验，新枪械和新升级可通过注入扩展；
- 七把枪械都有唯一 `visualId`、独立像素轮廓、独立合成枪声及有效的近/中/远射程分类；枪口、后坐和抛壳参数均通过内容契约校验；
- 部署页不再包含隐藏枪械快捷切换；背包页的直接武器/服饰选择会校验解锁状态并持久化，Esc/B 返回部署页；
- 旧存档升级到 schema v8 时保留进度与显式设置；v5 的护甲/工具/挂件会迁移到四部位，新增教学、熟练度、最近 20 局、键位、静音、UI 缩放和成就字段均安全归一化；
- 首次教学只响应当前步骤对应的真实玩法事件，完成/跳过会持久化；结算的实际伤害、弹体命中率、最长无伤和熟练度由模型统一结算；
- 三章节音乐按 stageId 稳定回退，并根据局内进度、危机和 Boss 状态增加压力声部与 Boss 动机；WebAudio 缺失时安全降级；
- 自动锁定仅选择当前枪械有效范围内的最近敌人；范围外无锁定、无自动射击，且不绘制连线、LOCK 或敌人方框；
- 失去窗口焦点与页面隐藏使用同一暂停生命周期，不继续模拟或积累补帧；
- 地图数据包含可复用的商店街、主干道、服务区、货场铁轨和拆车场坐标，所有碰撞地标均已检查在世界边界内；
- 固定 60 Hz 逻辑、最多 4 步追帧，超额积压被记录并丢弃；
- 画质降级不改变战斗实体和 DPR；
- 模型最内层限制敌人 128、玩家弹体 180、敌方弹幕 120、拾取物 140；无尽 Boss 阈值只在成功生成后推进且同一波不重复；
- 玩家和敌人碰撞均使用局部障碍网格；穿透弹用池内 Set 去重；小/中/大敌人使用三档 clearance；薄障碍不会漏烘焙；不连通地图启动即失败；
- 部署、人体四槽、20 格背包以及商店枪械/服饰/装备三分类在 568×320、1280×720 与 1920×1080 的所有点击区域均有正面积且不越出视口；
- 页面正文使用系统易读字体，Fusion Pixel 只承担标题和短标签；主文字组合的自动对比度门槛不低于 4.5:1；
- 页面框体优先通过 `field-surfaces` 和真实 Alpha 铭牌绘制；九宫格四角等比缩放，只拉伸中心带；素材不可用时才回退到统一程序化原语；
- 封面图使用 contain 安全构图，图片四边均在视口内，最大变异体头部与下方角色轮廓不得再被裁切；
- 活动 Art Catalog 只登记当前 10 个图片；旧部署源码和 v1.0/v1.1 素材保留归档，但都不进入 bundle、Web 活动树或初始图片内存；
- `art/manifest.json` 中每个源图、归档、运行图和 inactive 变体都必须存在，声明 SHA 的运行图必须逐字节匹配；
- 多策略模拟器逐帧消费事件并输出承伤来源、升级顺序、阶段、Boss 时长、铜币曲线与 heap/RSS；
- 桌面 bundle 小于 1 MB，运行源码无远程资源依赖。

## Windows 人工验收顺序

1. 1280×720 窗口启动，键鼠完成菜单、升级、暂停和结算；
2. 游戏运行中插入 Xbox 手柄，确认图例切换且移动连续；
3. 轻推左右摇杆验证死区，再测试 RT、RB、X、A、B、Menu；
4. 保持移动时拔出手柄，确认角色立即停止且没有持续射击；
5. Alt+Tab、最小化、恢复，确认自动暂停且没有补帧爆发；
6. 检查主菜单主题图与菜单是否自然融合、部署页运输车入口、背包 20 格布局、商店六把可购枪械的独立轮廓、四张升级卡正文与 Fusion Pixel Font 加载，再以 1920×1080 全屏运行 8 分钟，记录 FPS、内存、音频爆音和手柄延迟；
7. 开启性能信息，确认实体上限和补帧丢弃计数合理；
8. Chrome 重复关键流程，并用至少一种第三方 XInput 手柄复测。

## 通过门槛

- 1080p 常规场景保持约 60 FPS；
- 1% low 目标不低于 50 FPS，最低环境持续不低于 30 FPS；
- 不出现输入卡住、菜单连续跳转、断线持续移动或恢复后加速；
- 8 分钟对局没有持续内存增长趋势；
- 键鼠和标准手柄都能独立完成完整流程；
- 所有自动测试、构建和模拟继续通过。
