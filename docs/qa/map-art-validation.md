# 地图美术与交互验证记录

日期：2026-10-30。当前是Godot原生内部地图迭代，完成本轮实现与自动检查，仍待本人试玩及设备矩阵。整体迁移状态保持“内部可玩、验收未完”，不作为正式Release或完美复刻声明。

## 已交付

- 三张地图保存可直接画/擦的GroundTiles；独立Profile、共享TileSet与材质实际被场景引用，避免编辑公共文件却只改到闲置副本。
- 16种地表变化与16个透明物件区域由两张共享图集提供；三图保留旧城、冷色货运、暖色赤砂的区别。来源、原图、提示词、尺寸与SHA见[素材包](../../art/world/pixel-map-v2/README.md)。
- 主角、池化敌人、环境物件、实体交互物和塔台按脚底Y排序；高物上部对玩家和附近敌人淡化，底座保持可见。
- 交易站按真实半径/视线显示提示；金币圆形、经验菱形，爆桶/补给独立图像，爆炸提示读取真实半径。键位提示读取自定义绑定，手柄输入切换A/Y说明。
- 塔台显示真实26×26底座与需复核通路的琥珀预览；补炮身到枪口的静态墙检查，防止极薄墙被枪口绕过。
- 文件夹导航、活动素材索引、精确重复组、历史/输出边界已生成；保留既有源稿与旧版回退文件，没有批量删除或移动。

## 画面与性能样本

保存960×540、1280×720、1920×1080、2560×1440的三图截图，以及商店前后遮挡、交易有效范围、补给、爆桶和密集敌群局部截图。最终大地图出生样本采用各地图实际默认出生位置，避免截图夹具把角色强行放进建筑。

当前已目视检查三图代表画面、屋前/屋后、交易与密集敌群。完整截图在output/godot-migration/native-play及output/map-art/review，不进入源码Git。其余非默认组合和实际移动中的信息识别仍需试玩。

本机RTX4060 Laptop、Compatibility/OpenGL、1280×720、上限60fps，104敌与17物件：预热60帧、采样120帧，中位16.666ms、P95 18.076ms。敌人绘制指令按动画帧/朝向/受击状态失效，不每帧重复重建；没有建立统计上的提速结论。该样本约数秒，不能证明低配、长期内存稳定或所有战斗场景满足60fps。
