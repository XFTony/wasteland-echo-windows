# 回声旧城地面样板与UI验证

日期：2026-10-30。仅重做回声旧城地面，现有建筑/车辆/角色/敌人保留；货运与赤砂未更换美术。当前为内部样板，等待本人审美和游玩确认。

## 本轮结果

- 沥青、积尘土面、混凝土和道床按连续世界坐标采样，消除旧64单位图块染边；平移交叠处理原图边界，替换第一轮镜像对称纹样。
- 八类绘制细节用于路缘、标线、斑马线、裂缝、积尘、油迹、散落铺砖和轨道；路口不会横穿内部路缘。建筑底部使用不规则接地细节。
- 四张升级卡都响应真实鼠标悬停；默认键盘焦点不再把第一卡长期抬起。只移动绘制画面，点击区域固定。
- 键盘/手柄与指针反馈互斥；连续窗口调整保留所选内容ID；小窗口两行卡片标题与底部按钮布局已整理。
- 启动画面接收内部减少动态偏好，禁用手柄时不显示错误手柄提示；署名页删除旧网页Gamepad API与技术重构字样。

## 仍需本人确认与后续顺序

1. 先比较旧城道路和旧铺：材质是否与现有精细像素物件协调，是否仍有贴纸感；走位时敌人/敌弹是否容易辨认。
2. 升级时把鼠标依次移入1—4卡、移出、再移回第一卡，检查反馈节奏是否一致；也可用键盘导航切换。
3. 审美确认后再推广另外两图。若地表仍嘈杂，先改反差/铺砖尺度/疏密，不继续堆装饰。
4. 长局、低配、实体手柄和Windows显示缩放继续补证据。本轮不能替代这些验收。
5. 原生设置页尚无独立“减少动态”开关，Windows系统偏好未接入；本轮验证的是传入内部标志时的正确行为。后续补UI入口、默认值、存档白名单与旧档兼容后，才视为用户可选功能完成。
