# 巡线者默认服饰：关节与可替换部件样板

状态：2026-09-28 内部动作样板。只覆盖 `ranger/wanderer`；其他主角、服饰和敌人继续使用原有静态身体。动作层不修改碰撞、武器数值、60 Hz 逻辑、内容 ID 或存档。

## 为什么重做

第一版把完整左右腿当作两根硬杆绕胯旋转，膝盖没有运动；上身源图仍包含垂下的两只手臂，游戏又独立绘制枪。这造成不自然步态和四只手臂的视觉错觉。第一版两张运行图已标为 inactive，源图与构建脚本保留供回溯，不进入新版桌面资源目录。

## 参考与原则

- [Spine Skins 官方说明](https://esotericsoftware.com/spine-skins)：骨架动作与皮肤附着物解耦，服饰可以替换部件而复用同一动作。这里借鉴其部件槽位思想，继续使用项目现有 Canvas 2D 渲染，不引入 Spine 运行时。
- [Spine IK 官方说明](https://esotericsoftware.com/spine-ik-constraints)：两节骨骼由手或脚的目标位置反求肘、膝角度；这比仅旋转整条手脚更适合持枪和脚步着地。
- 类似《饥荒》的分部位纸片角色强调动作、朝向与衣物替换共用骨架。本样板先验证正面偏三分之四视角的行走与双手握枪，背向和更多角度需要新画稿，不能靠镜像冒充完成。

## 素材与骨架契约

源图：`art/generated/v1.5/source/ranger-wanderer-upper-rig-v2-source.png` 与 `ranger-wanderer-lower-rig-v2-source.png`。两张原图都是真透明厚涂图，分别提供无手臂上身、左右上臂、左右前臂，以及左右大腿、小腿、靴子。`scripts/build_ranger_joint_assets.py` 只裁切和缩放这些已画好的部件，按下表固定顺序打包为一张 `512×384`、每格 `128×128` 的 WebP 图集。部件在单元格顶部留 8px 枢轴边距，绘制时用相同的关节长度标定。

| 部件槽位 | 父关节 → 子关节 | 装备扩展 |
|---|---|---|
| `torso`（含兜帽和面罩） | 根部 → 头/肩/胯锚点 | 胸甲覆盖层与头盔锚点；头仍与躯干共用绘画件 |
| `upperArmLeft/Right` | 肩 → 肘 | 袖子、肩甲 |
| `forearmLeft/Right` | 肘 → 握枪手目标 | 护臂、手套；手绘在前臂末端 |
| `thighLeft/Right` | 胯 → 膝 | 裤装、腿挂 |
| `shinLeft/Right` | 膝 → 踝 | 护胫、布条 |
| `bootLeft/Right` | 踝 → 脚尖 | 鞋靴 |

部件索引、槽位集合和头/肩/胯/枪械锚点集中在 `src/render/ranger-rig.js`。以后为另一套服饰绘制相同 11 个槽位，可复用动作数学；独立护具须按对应关节制作透明覆盖部件。不能直接放大背包物品图标充当穿戴层。

## 动作与持枪

`src/render/ranger-motion.js` 只读取实际世界位移，记录步态相位、运动方向和起停混合值。撞到障碍而不位移时逐渐收脚；暂停时状态冻结；换局或异常位移时重置。身体与镜头位置仍由现有世界数据决定。

每条腿采用胯—膝—踝的两节反向运动学，脚在支撑段沿运动反方向移动，在摆腿段抬起并向前；靴子独立连接踝关节。左右手分别以枪柄和前端支撑点为目标，肩—肘—手的两节反向运动学保持握持。七把原有枪械图继续独立旋转；上身、手臂和腿部围绕同一角色根部定位。

## 验收边界

- 自动测试：关节长度、槽位、实际位移驱动、停步、暂停、换局、静态回退、11 部件和枪械分层顺序。
- 画面：默认服饰在原始游戏尺寸下核对静止、连续移动、左右/上下瞄准及七枪握持；生成的短 GIF 仅作内部对比，玩家以 Windows 实际窗口体验为准。
- 性能：仅当前选中的主角加载这张关节图集；它与其他战斗素材一起在回主菜单时释放。普通敌人没有改成逐人关节绘制。
- 快速对照：Edge headless 1080p/120 敌人短样本中，关节路径平均约 7.67 ms，静态人物路径约 7.53 ms，1% low 都约 48 FPS；此值低于项目文档的 50 FPS 目标，不能替代真实 WebView2 窗口和长局验收。
- 未完成：头部独立转动、背向重画、不同服饰部件、真实护具覆盖、倒地和受击专属姿势。玩家审核本样板后再决定这些内容的制作规格。
