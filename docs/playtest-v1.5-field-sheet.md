# 《荒原回响》v1.5 真人试玩记录表

状态：待人工填写。此表专门记录持有 Windows 电脑和实体手柄的真人体验；自动模拟、脚本截图和 headless 帧率不能代填。

## 试玩前

1. 使用当前 alpha 便携版或安装版；记录文件名、版本、Windows 版本、CPU/GPU、显示分辨率与缩放比例。先复制整个 `%LOCALAPPDATA%\com.wastelandecho.desktop` 文件夹作为存档备份。
2. 游戏设置中打开 FPS 信息；记录自动瞄准、自动开火、闪烁、震动和 UI 缩放。每一局写下 seed、英雄、武器、护具和挑战选项，避免只写“第一关”。
3. 若愿意录屏，请在局后记录出现困惑或卡顿的时间点。无需公开个人信息、系统用户名或完整用户数据目录。
