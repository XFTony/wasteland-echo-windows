## 素材制作与代码边界

1. 新图先做一件样板：源 PNG → 透明边缘和姿态检查 → 缩到实际像素检查 → WebP 压缩 → 清单 SHA 和许可登记 → 浏览器截图 → 真实 Windows 窗口检查。未通过时先修原画或锚点，不批量铺开。
2. 角色图使用可重复的身体、服饰/护具覆盖和独立武器。动作与外观依赖视觉 ID；生命、伤害、碰撞和进度继续由现有内容数据驱动。
3. 地图对象用重复材质、图集和独立地标，位置只取自世界注册表。高频战斗区的背景局部对比应低于敌人与危险提示。
4. UI 保留清楚的中文正文、鼠标悬停与手柄焦点；图像失败时仍可选择、购买、装备、暂停和退出。
5. 每个工作包作为独立 Git 提交进入 `feat/illustrated-overhaul`；检查点可回退。未完成覆盖前不合并 `main`、不打发布标签。截图放 `output/`，正式包放发布资产，不把本地测试图混进活动素材树。

### 每件新图的停工门槛

1. **源图审查**：角色身份、完整肢体、透明边缘和同一光源成立；服饰不得改变内容 ID 对应人物。未通过则只修这一件。
2. **运行图审查**：在真实 76px 战斗大小和背包尺寸下仍可辨；握枪、左右/上瞄准、移动、受击不遮住关键特征。当前技师样板发现并修正了手枪遮面问题。
3. **工程审查**：登记源 PNG、优化 WebP、裁切尺寸、SHA 与来源；素材缺失仍可操作。运行图预算暂以 12 MB 为工作上限，超限先看实际解码内存再决定图集或降采样。
4. **发布审查**：全部组合和三图对象统一后，才跑真实 WebView2、实体手柄与安装包；未通过前不合并 `main`、不打 `v1.5.0-alpha.2` 标签。
