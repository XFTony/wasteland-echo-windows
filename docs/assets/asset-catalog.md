本次活动树原始文件 **86** 个 / **10.36 MiB**，另有 5 件运行时原生绘制武器。

`.import` 是导入设置，不重复计为美术原文件；它们保留在完整文件索引中。动态拼接的 ID/路径无法仅凭静态查找证明未使用，因此未注册项一律列为复核项。

## 新增素材的保存步骤

1. 活动图片/音频放Godot功能子目录，保留稳定ID和.import设置；源图、分层文件、原采样放art相应工作包。
2. 同步来源/许可记录，声明生成原图、参考输入、处理脚本与运行图关系；未核实的许可标为待核实。
3. 把真实路径登记到原生Resource或场景，按运行尺寸检查边缘、接缝和交互可读性。
4. 运行本脚本重建索引；在Git提交中保存源码/素材与来源，完整截图/大包留output。
5. 只有引用检查和实际验收均确认停用后，再单列归档/删除清单，避免改路径破坏存档或场景引用。
