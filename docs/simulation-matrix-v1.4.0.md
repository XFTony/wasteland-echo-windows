## 结论

1. 旧“单一环绕代理获胜”不能代表普遍难度；同 seed 下只有 2/6 策略完成；
2. 风筝策略击败数更高却在 Boss 阶段死亡，说明远程投射物与 Boss 压力需要单独分析，不能只看击杀；
3. 贴脸策略在 35.42 秒快速失败，接触伤害有明确惩罚；
4. 无磁吸场景接近终局但失败，拾取与升级路线对存活有显著影响；
5. 撤离优先代理因几乎不拾取经验，在 74.37 秒被腐蚀者击败，说明撤离模式需要“先成长、后前往信标”的策略；它不是撤离模式胜率结论；
6. 自动锁敌代理命中率偏高，仍不能替代真人键鼠或手柄命中率。

## 使用规则

- `npm.cmd run simulate:matrix` 重新生成原始 JSON；
- 平衡文档引用模拟结果时，至少同时列出完成率、结束时间、承伤来源和升级序列；
- 压力生命模拟只证明长局稳定性，不参与难度结论；
- v1.5 前仍需完成 `docs/playtest-v1.4-notes.md` 的真人矩阵。
