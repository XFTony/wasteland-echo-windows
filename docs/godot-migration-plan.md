## 不可省略的迁移合同

- 保留12件武器、8类敌人、3地图、3英雄、3服饰、8装备、34升级、现有Boss/机制/解锁/熟练度和全部商店ID；从活动内容注册表导入，不凭文档摘要手工重填数值。
- 保留连续生存、自动瞄准/射击、地图交易、四塔上限和全部已存在设置。旧限时模式与旧档兼容路径也须登记，不能被新的正常入口误删。
- 当前Canvas/Tauri版作为逐项对照基准。Godot版使用原生场景、Control、Resource、AudioStream与GDScript；不嵌入旧网页冒充迁移，不把截图按钮当作真实界面实现。
- 游戏判定来自固定60Hz模拟；渲染、动画和粒子不反写数值。暂停、失焦、换局、近战切换、存档恢复等边界逐项复验。
- 图像、图集、字体、源音频、许可与来源记录继续使用原资产。允许修复错误、资源泄漏和低效路径，影响玩法或审美的变化独立记录，先达到复刻再另行优化。
- 不宣称“完美复刻”直到全部行为检查与同分辨率截图对照通过；不能用导入数值通过代替UI、战斗、存档或设备验收。

## 官方规范

- [项目组织](https://docs.godotengine.org/en/stable/tutorials/best_practices/project_organization.html)：按功能组织场景与配套脚本，snake_case文件，PascalCase节点，`res://`运行资源、`user://`存档。
- [GDScript风格](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_styleguide.html)：UTF-8无BOM、LF、Tab缩进、静态类型、信号、每行一条语句。
- [Resources](https://docs.godotengine.org/en/stable/tutorials/scripting/resources.html)：可配置内容以自定义Resource组织，不复制代码中的数值。
- [场景组织](https://docs.godotengine.org/en/stable/tutorials/best_practices/scene_organization.html)：组合、清晰的依赖方向、父节点协调，纯数据不滥用Autoload。
- UI使用Control/Container/Theme并保存原布局职责；需要忠实表现的纸卡、布面和图标采用原生自定义绘制。地图可用Node2D和TileMapLayer混合，不强迫将自由摆放物体改为方格地图。

1. 输入：鼠标/键盘/手柄、自动/手动切换、目标保留、死区、断线、重绑定冲突、焦点、暂停/隐藏/恢复清零。
2. 战斗：真实枪口、贴身/薄墙、同敌去重、穿透次数、暴击、攻击ID、霰弹推力上限、反弹、寿命末段、范围墙体遮挡。
3. 近战：前摇/有效/收招、移动独立、瞄准锁定、切枪取消、剑气、锤击落点、短时消弹，关闭闪光仍有轮廓。
4. 世界：三图所有碰撞/道路/地标/交互点、补给、油桶、减速区、合法出生/部署，三档clearance和流场更新。
5. 进度：经验升级、候选前置/上限/重复项、局内局外货币分离、购物暂停、按战斗计时补货、装备组合、精通/解锁幂等。
6. 存档：默认/旧schema/异常/未知ID/主档损坏/备份损坏/写入失败；导入前预览与备份，不直接扫描或覆盖WebView2数据。
7. UI：每个页面与弹窗的内容、尺寸、文字、图标、层级、禁用态、悬停/焦点/点击、分页、缩放和键鼠/手柄可达性。
8. 音画：短采样真实播放、流式音乐/交叉淡化、静音与失焦、后坐/抛壳/命中/消弹、减少闪光/抖动、数量上限。

## 交付规则

- 当前已认可美术与玩法不因迁移重做。功能分支定期保存，完整截图/录屏/构建放output；源码、源数据、精选截图、许可与测试入Git。
- Godot源脚本UID入Git；`.godot`导入缓存不入Git。可再生的资产导入副本使用来源清单与SHA校验，避免两份素材分别修改。
- 正式发布前取得旧档与新包对照证据，不自动迁移用户真实存档，不提前打版本标签或Release。
- 实体手柄、最低配置与真人听感须真机完成；自动测试通过只能对应它实际覆盖的行为。
