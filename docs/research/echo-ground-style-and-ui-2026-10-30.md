# 旧城地面、风格整合与UI动态审查

日期：2026-10-30。以本项目试玩截图和实际原生代码为依据，优先修复精细环境物件与地面割裂的问题。本轮只制作回声旧城样板。

## 美术诊断与实际方案

**根因不只是像素精细度。** 原图块每64世界单位的统一染边、规则道路线条、重复纹理和规则建筑底影同时存在。即使换更大的PNG，仍会像两个图层。

1. **同一套材质规范。** 保留用户认可的房屋、集装箱和车辆作为基准，生成沥青、土面、混凝土和货场道床。中性暖光、灰褐/橄榄/锈色，细节按小色块组织；地面保持较低对比。
2. **连续材质而非小格框。** 地表按世界坐标采样，由原道路/地块矩形计算并集。混合不改变通路和碰撞，也不再给每块小格涂同一圈底色。
3. **避免镜像纹样。** 第一轮实窗发现镜像重复形成明显对称图案，已改为平移采样交叠，处理图像边界连续性；不是声称生成原图天然无缝。
4. **绘制道路语义。** 路缘、排水沟、掉漆标线、斑马线和轨道用透明素材区域；在道路相交处减去内部路缘区段。可以用代码放置已有绘画素材，避免让规则几何本身充当全部美术。
5. **接地关系。** 建筑/车辆底部放低对比积尘、油迹和局部铺砖，替换旧城的规则多边形底影。旧有深度排序和上部淡化继续工作；新增地面碎石/污迹明确为可走贴花。
6. **量产方式。** 两张1254方图复用；源图、提示词、区域、SHA和活动副本统一登记。不为整图制作一张大位图，也不同时把另外两图改成未经用户确认的新样板。

源图粒度和地面反差仍要通过实际游玩确认，不能仅凭高分辨率截图宣布通过美术验收。

## UI与动态审查

| 元素 | 发现 | 本轮处理/验证 |
|---|---|---|
| 升级第一卡 | 默认focus与hover合并，首卡长期抬起，鼠标进入没有新变化 | 输入来源决定当前采用鼠标悬停还是导航焦点；鼠标移入四卡均触发同一套动效 |
| 升级卡点击区域 | 移动/旋转Button本体，视觉与命中区域一起变，边缘可能反复触发 | 保留固定按钮槽，只变绘制矩阵；五种尺寸逐卡测试进入、移出、边缘、点击ID |
| 键盘/手柄切换 | 指针停在另一张卡时可能同时亮两项 | 导航模式只显示当前focus；鼠标移动后恢复指针优先，保留原生焦点供再次导航 |
| 窗口尺寸变化 | 原refresh只恢复RadioButton焦点，UpgradeCard选择丢失 | 也按升级内容ID恢复；真实resize后验证选项保留 |
| 减少动态效果 | 旧实现只是立即到达抬起/缩放终点，仍会跳动 | 升级卡保持恒等视觉变换，仅用纸色/描边反馈；不缩放、不位移、不旋转、不淡入 |
| 启动画面 | 未读取reducedMotion；禁用手柄时提示仍可能按连接数显示A/B | 修正内部偏好路径：传入减少动态时显示静态标题并缩短等待；手柄提示/跳过遵循启用设置 |
| 菜单/行装/商店/设置 | 使用RadioButton的轻微绘制偏移和独立焦点边线，未像升级卡移动命中区域 | 四分辨率截图、动作区域回归；静态边线保留键盘可访问性，不扩大本轮为整套UI重做 |
| 暂停/交易/结算 | 沿用原生可聚焦控件和输入门控，模型回归已覆盖主要流程 | 本轮重新做对应布局截图与区域检查；实际手柄/系统DPI验收不由截图替代 |

升级卡区域比较也明确调整：旧版动画AABB保留作历史记录，新的点击区域与原版静止槽位比较。不是用旧错误的移动命中框要求新实现继续抖动，也不把布局通过当作动效通过。

目前原生设置页尚无独立的“减少动态”开关，Windows系统偏好也未接入。本轮修正并测试了内部传入该偏好时的表现，未把它宣称为已经交付的可选菜单功能。后续应将入口、默认值、存档字段白名单与旧档兼容一起补齐。

署名页还保留了旧网页的“Gamepad API”和技术重构文字，本轮改为面向玩家的键鼠/手柄能力与内部试玩版说明，避免继续展示已失效的实现细节。

## 后续判断

先让本人比较旧城同位置前后画面和四卡动态，再决定是否推广到货运/赤砂。下一步若仍显嘈杂，应减少大面积材质对比、调整铺砖尺寸和疏密，优先保住走位时的敌弹可读性；不能继续用叠加更多垃圾/噪点来掩盖融合问题。
