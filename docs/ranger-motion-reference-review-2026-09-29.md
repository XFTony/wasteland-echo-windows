## 第三方动作参考的核查

候选来自 [OpenGameArt: Base Rigged Stylized Humanoid Character](https://opengameart.org/content/base-rigged-stylized-humanoid-character-yw)，作者 Girush。下载包内 `readme.txt` 标明 **CC0 / Public Domain**；本地压缩包与模型仅在被 Git 忽略的 `output/third-party/`，没有作为项目素材提交或接入。压缩包 SHA-256：`89B885CE4ACB7663C236D4602B4F6E44E3384E153049F897F9B383CEEE16AACB`。使用 Blender 5.2.2 的 `--disable-autoexec` 只读打开：模型有 65 根骨骼，`run` 为 1–30 帧，`run_armed` 为 0–30 帧。这里的授权判断依据是候选包自身的许可文件，正式复用前仍须保存来源快照。

按项目临时镜头渲染 `run` 与 `run_armed` 各八帧，统一摄像机、透明背景和**跨全部帧的固定裁切/缩放**，再放到实际地图背景的 76px、152px 面板：`output/animation/ranger/girush-reference/comparison-76px.png` 和 `comparison-152px.png`。固定裁切很关键；逐帧裁切再把每帧拉到同一高度会人为掩盖头部起伏、脚底漂移及角色尺寸变化。

观察：参考跑步动作的腿部前后关系比自制体块明显，说明当前灰模的腿部姿势幅度和可见面积不足；但它采用夸张的高抬腿、后踢和腾空，且上身是奇幻人物的跑姿。`Foot.L` 骨骼末端在第 1 帧约升至 80.6 个模型单位，而人体高度约 175 个单位；第 17 帧脚部骨骼末端约为 -1.4，提示接地约束也需复查。这些是骨骼末端坐标，不等同靴底实际高度；视觉对照依然足以排除直接移植。`run_armed` 与 `run` 主要差在上肢，未形成巡线者的双手枪柄/前握位。

**决定：只借鉴其“有体积的腿部剪影”和骨架组织，不重定向整套动作，也不使用模型外形。**它在 76px 下展示出跑动，但节奏和姿势不适合本游戏的俯视持枪移动。

## 下一轮单人样板的具体修改

1. 锁定用于样板的镜头、模型尺度、脚底世界锚点。比对板保持一套固定裁切，不随姿势改变缩放。镜头仍须玩家确认，先不把 42° 当作最终美术参数。
2. 放大**可见的小腿、靴子间隔**，调整长外套开衩与遮挡；保留原画兜帽、面罩和外套身份。按接触、下沉、经过、腾空明确双脚世界位置和骨盆高度，逐姿势检查靴底触地及膝盖弯曲。不要继续靠正弦参数或旧成品插画切片修补。
3. 先做四个无枪姿势的**同屏静止对照与短循环**。76px 与 152px 均能辨认两脚关系，并且脚底不会交替滑行，才做向后和横移动作。节奏以真实位移与步幅对应，世界坐标不由动画驱动。
4. 之后添加独立枪柄手与支撑手控制器，核对肩、肘、腕和枪械在前进、后退、横移时的关系；不同枪械仍用现有内容 ID。再进入厚涂材质、图集和游戏接入。

本轮没有补中间帧、压制图集或修改运行时代码。阶段 B 仍未通过；下一次的成果应是**新的可观察动作样板**，而非增加当前失败动作的帧数。

## 后续执行记录：先修骨架基础

对旧灰模作了腿部独立渲染及打开外套下摆的诊断。独立的腿在 256px 可以区分；整身缩到 76px 后，外套、头肩和横在胸前的手臂仍让四个姿势显得相近。还发现旧脚本用 `scale.z` 随每帧改变大腿和小腿长度，这不符合真实关节运动。

因此建立了 `ranger-rig-graybox-v1.blend`，由 16 根真实骨骼与脚部 IK 控制点驱动，取代旧脚本的逐帧伸缩。四个技术目标位置经 Blender 验证，骨长固定、脚踝误差小于 0.005 米；76px 对照在 `output/animation/ranger/rig-v1/technical-poses-76px.png`。**技术验证通过，视觉验证仍未通过。**没有把试验姿势存成正式动作，也没有进入游戏。

下一项工作是按原画重建衣摆开衩、腿部体积和上肢，给骨架人工制作接触/下沉/经过/腾空姿势。若仍无法在 76px 看清脚与重心，停止调整灰色体块参数，改为逐姿势修画或寻求专业角色动画制作；不要先补帧、上色或接入 Canvas。

## V2 灰模动作试验及当前决策

在固定骨长骨架上改造了开襟外套、背后衣摆和双臂 IK，并分别保存为 `ranger-silhouette-v2.blend`、`ranger-run-ik-v2.blend`。第一次短循环暴露出两个具体错误：靴子跟随小腿倾斜，最深穿地约 6 厘米；“经过”姿势提前换脚，形成同一只脚短时间重复落地。修订后靴子由脚部控制点带动，接触、下沉、经过由**同一只脚**连续支撑，飞跃后另一只脚接地。支撑段的脚部后移设为线性，不用默认贝塞尔在接地两端减速。

当前 24 帧技术验收通过：脚、手控制误差为 0；骨长不变；左右支撑脚各连续接地 7 帧；支撑脚每帧后移约 0.08167 米；靴底最低约 -0.0085 米；循环首尾控制点一致。该步幅大致对应项目默认约 170 世界单位/秒、角色高度约 76 世界单位的移动尺度，正式播放仍应按**实际世界位移**推进步相，不能用固定计时忽略加速、撞墙和升级。完整循环与 76px/152px GIF 位于 `output/animation/ranger/run-ik-v2/loop/`；短片使用灰模和临时镜头，只作内部评审。

目视仍有问题：人物头肩相对较重，外套和上肢的体积、衣褶及人物身份尚未达到现有厚涂原画水准；没有带枪前进、后退和横移样板。因此阶段 B 只算**技术样板可重建，未获玩家审美认可**；C–F 仍未完成，不接入游戏、不发行预览。已生成 `output/animation/ranger/run-ik-v2/review.html`，可暂停、逐帧、切换游戏尺寸，且经本地 Edge 打开验证。下一步先请玩家看实际尺寸短循环，针对腿部幅度与人物比例修 3D 源，再做双手持枪和画风处理；不扩展敌人或其他服饰。
