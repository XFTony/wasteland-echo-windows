# 《荒原回响》v1.5 数值与体验记录

> 2026-09-23 复跑六策略正常生命矩阵：3/6 通关（默认环绕、随机升级、无磁吸）；风筝 155.57 秒、贴脸 100.33 秒、撤离优先 62.35 秒失败。下方 2026-09-21 的 2/6 为历史快照。当前数据见 `simulation-matrix-1.5.0-alpha.1.json`；真人结论仍待 `playtest-v1.5-field-sheet.md`。

## 当前 v1.5.0-alpha.1 技术基线（2026-09-21）

- 小/中/大型敌人改用三档 clearance，薄障碍采用格子相交补充烘焙；此变化会改变敌群到达路线，因此 v1.4 单代理击败/生命数据只作历史比较；
- 正常生命、同 seed 的六策略矩阵完成率为 2/6：默认环绕与随机升级通关；风筝、贴脸、无磁吸和撤离优先均失败；
- 默认环绕：221 击败、最终生命 78.90；随机升级：237 击败、最终生命 58.89；
- 风筝在 137.22 秒主要死于突袭者，贴脸在 146.92 秒主要死于重甲者，无磁吸在 170.62 秒失败；
- 撤离优先代理 56.28 秒死于腐蚀者，说明“直接守信标、不拾取成长”不是有效策略；
- 完整 Edge 真页面矩阵覆盖 18 场景；平均 142.43～144.05 FPS，最低 1% low 72.46 FPS，无页面错误或 >33.3 ms 严重帧；
- 模拟与浏览器数据分别见 `docs/simulation-matrix-v1.5-alpha.md` 和 `docs/browser-fps-v1.5-alpha.md`；两者都不能代替真人试玩。

## v1.3 冻结基线（2026-09-19）

> 本节及以下 v0.x 内容均为历史快照，不代表现行规则。当前默认局长为 180/210 秒，新存档默认开启范围内最近敌人自动锁定；稳定版数值以 v1.4 基线为准，开发线变化见页首 v1.5-alpha 基线。

- 内容边界：7 把武器、8 类敌人、14 项基础升级、4 项终局进化、3 名主角、3 张地图、3 个章节、6 件四部位装备、8 项成就；
- 三种模式共用六段生成导演；无尽不会按计时自动结算，Boss 成功生成后才推进波次，敌人硬上限 128、常规无尽软上限约 104；
- 敌人拥有障碍碰撞、确定性群体分离、坦克冲锋、警报者尖啸和 Boss 三阶段；尚未实现全局绕障寻路，复杂建筑区可能出现贴墙聚集；
- 三张地图各有独立道路细节及爆炸桶、补给箱、电磁减速区；交互位置由 WorldRegistry 数据驱动；
- 固定 seed `20260907` 的 180 秒正常生命坚守代理获胜：最终生命 15.26、203 击败、等级 6、峰值 79 敌人 / 25 投射物 / 140 拾取物；纯模型耗时约 829 ms，堆峰值 10.34 MiB、RSS 峰值 62.43 MiB；
- 同 seed 的 600 秒无尽压力代理完整跑满并保持 `running`：1510 击败、等级 26、3 波 Boss、峰值 105 敌人 / 87 投射物 / 140 拾取物；压缩时间模拟耗时约 7.07 秒，堆峰值 54.68 MiB、RSS 峰值 126.34 MiB；
- 最新自动验证：135 项测试通过；浏览器 bundle 426,142 bytes；精简 `dist/` 5,010,164 bytes；便携 exe 13,139,968 bytes；
- 180 秒代理仅剩 15.26 生命，表明 v1.3 相比旧基线容错明显降低。它仍不是首局真人胜率结论；寻路上线后必须重新记录同 seed 与真人试玩数据。

## v0.5 三分钟尸潮与城市战区

- 默认对局改为 180 秒。坚守模式不再采用单条线性生成间隔，而是“试探（0–22 秒）→累积→第一波冲击→短暂喘息→围攻→最终攻势”的六段配置；每段同时定义生成间隔与活跃敌人上限；
- 默认坚守数值为 12 → 20 → 34 → 26 → 52 → 78 只活跃感染者。中局上限回落，让玩家有时间拾取经验和整理走位，后两段恢复明显压力；
- 自动瞄准改为枪械数据驱动的有效锁定范围：手枪 520、冲锋枪 420、霰弹枪 250、步枪 680 世界单位；射程升级会同步放大锁定距离。范围外不会自动锁定，也不会因自动开火向旧方向射击；
- 180 秒固定 seed `20260907` 的正常生命代理坚守获胜：最终生命 40.32、205 击败、等级 5、峰值 79 个敌人 / 23 个投射物、纯模型耗时 108.53 ms。它是回归代理，不代表真人首局胜率；
- 战区布局提取为 `src/world/wasteland-map.js`：旧城商店街、服务区、主干道、铁轨货场和拆车场以统一坐标供碰撞与渲染复用。地表纹理为本地生成资产，台账状态为发布前复核；

## v0.4 目标锁定与表现重构

- 主菜单改为“主页 → 作战部署 → 确认出征”三段，避免在首屏混放模式、枪械和皮肤选择；
- 最近存活敌人锁定为默认规则，旧 schema v1/v2 存档迁移到 v3 时启用；关闭后仍可用修正过相机原点的鼠标/右摇杆手动瞄准；
- 幸存者和感染者改由 `pixel-actors` 的阴影、四肢、躯干、头部、武器/职业饰件分层组合；
- 升级四选一改为稀有度宝石、双层边框、扇形入场与装配反馈的收藏卡式表现；
- 验证快照：70 项自动测试通过；bundle 221,722 bytes；60 秒和 480 秒正常血量坚守均获胜。480 秒模拟为 842 击杀、最终生命 42.68，逻辑耗时 183.29 ms。

## v0.3 Windows 桌面迁移

- 新存档默认关闭自动瞄准与自动开火，键鼠和双摇杆手柄承担主动瞄准；旧存档设置不被强制覆盖。
- `aimActive` 成为输入契约的一部分：鼠标或右摇杆的明确方向优先于辅助瞄准。
- 当前敌人数量与伤害曲线暂不因平台迁移而提高；先完成 1080p 真人键鼠/手柄首局胜率与 8 分钟性能记录，再调整 PC 端密度。
- 实体上限改为可注入运行参数，默认仍为玩家弹体 180、敌方弹体 120、拾取物 140，避免把“PC 性能更高”直接等同于可以无限扩容。
- 性能信息开关显示 FPS、帧耗时、活动实体、空间网格和追帧丢弃，用真实数据决定后续画质与密度档位。

## v0.2 历史基线（2026-09-08）

### 模式

| 项目 | 坚守模式（默认） | 撤离模式（挑战） |
|---|---:|---:|
| 胜利 | 倒计时归零且存活 | 终局信标内同步 2.5 秒 |
| 初始生命 / 移速 | 115 / 178 px/s | 100 / 170 px/s |
| 初始敌人 | 1 | 2 |
| 常规敌人软上限 | 64 | 80 |
| 生成间隔 | 0.95s → 0.32s | 0.64s → 0.16s |
| 敌人生命成长 | +45% | +70% |
| 敌人速度成长 | +7% | +12% |
| Boss | 进度 78% 时 1 个 | 进度 50% 与 93.75% 各 1 个 |
| 胜利奖励 | 25 废料 | 40 废料 |

- 正式单局：480 秒；浏览器调试支持 `?duration=60`；
- 坚守模式最后 30 秒进入“最终攻势”，无需前往撤离区；
- 撤离模式未完成同步时有最多 15 秒加时；
- 14 类升级，每次四选一；四个系列为火力、机动、生存、搜集；
- 受击无敌：坚守 0.72 秒，撤离 0.6 秒；
- 拾取物固定上限 140；满池后轮换合并同类价值并移动到最新掉落位置，不丢失经验/废料数值。

### 体验判断

- 60 秒坚守代理能以约 74% 生命完成，明显低于旧版撤离压力，符合“第一关用于熟悉操作”的目标；
- 180 秒与 480 秒结果说明默认曲线具备容错，但真人试玩仍需关注后半程是否过易；
- 同一代理在 60 秒撤离模式中约 34.9 秒阵亡，因此该模式明确标为挑战玩法，不作为首次进入默认选项；
- Windows 端最终数值必须结合键鼠命中率、右摇杆灵敏度、1080p 帧率和实体手柄输入延迟重新记录；历史移动端判断不再作为调参依据。
