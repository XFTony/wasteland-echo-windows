# 紧凑像素巡线者：转向与持枪动作设计记录

记录日期：2026-10-23。资料复核日期：2026-10-22。范围：一名主角的内部动态样板。

## 用户要求与当前方向

用户要求参考原版《元气骑士》的人物转向、持枪和移动射击表现，继续制作已确定的大头短身像素巡线者。保留沙色兜帽、深色面罩、橙色眼部和围巾及小手枪。

本轮沿用紧凑像素形象，不混入已停止的成人比例、写实关节或旧精细动画路线。角色参考源为 `art/characters/ranger/compact-pixel-v1/`。

## 公开依据与证据限制

直接依据是官方作者“游戏嘉”发布的[《春节预告》第00篇：8帧动画实装](https://www.taptap.cn/moment/89041328628828732)（2020-12-18）。原文明确介绍早期4帧、历史皮肤逐帧重画升级到8帧，以及开发环境中的动作重调；披风、耳朵、头发等附属表现也随之优化。该说明针对当时的历史素材升级，不代表现今全部角色、动作或皮肤统一使用8帧。

[原版《元气骑士》官网](https://soulknight.chillyroom.com/et)提供官方实机图库，作为人物比例与画面语言的参考入口。原预告正文已读取，但其中动态画面未完整进入文本抽取结果；本轮没有取得可逐帧测量的完整实机动作素材。

因此，本记录不声称已测定原版所有人物的朝向数量、镜像方式、武器与身体层序、手部算法、后坐时长或使用的软件。下列规则是参考后为本项目明确制定的实现方案，不能称为完整复刻《元气骑士》内部实现，也不混入《元气骑士前传》的资料。

## 本项目采用的六条动作规则

1. **身体保持紧凑的整个人物姿态。**头、躯干和短腿共同构成左右主朝向，不以成人关节扭转表现转身。移动采用真正交替换脚的逐帧短步；围巾跟随克制，轮廓与配饰身份保持稳定。
2. **身体主朝向与枪械瞄准分别控制。**身体使用左右外观，枪口覆盖全周方向。接近正上或正下时保留上一左右朝向，并在中线设置小幅滞回，避免临界位置不断翻面。具体参数由样板观察调整，不宣称来自原版测量。
3. **枪械与持握手组成一致的持握组。**先从身体源中移除烘焙的枪械和原持握部分，再使用独立持握组，避免重复手臂。向左瞄准时保持枪身、枪柄和手掌上下关系正确；握点、枪口及枪械外观随方向一致变化。
4. **为上向瞄准明确遮挡规则。**远侧手和枪械的适当部分可以进入身体后方，近侧部分按既定层序绘制；枪口、实际射向和必要的开火反馈必须清楚。层序是本项目规则，需重点检查头部遮枪、枪穿脸、手掌脱离枪柄等问题。
5. **用真实位移推进移动步相。**步态根据人物实际移动距离前进，停止或撞墙后收住；暂停、失焦和重开正确清理状态。移动方向与瞄准方向可不同，开火不能反复重置腿部步相。
6. **开火使用短促且可重触发的反馈。**持握组后坐与恢复、枪口亮点、子弹和音效围绕同一次开火事件触发；人物身体只做克制反应。站立及移动中均可射击，不因播放完整身体片段而延迟实际出弹。

## 本轮样板范围

- 一名紧凑像素巡线者、默认服饰和原起始手枪。
- 左右身体主朝向、全周枪械瞄准、逐帧短步及独立持握组。
- 可操作的移动、转向、站立射击和移动射击；提供自动情景以便对照。
- 真实位移驱动步相，重点检查上向瞄准与身体的遮挡。
- 内部独立样板，暂不全游戏接入，不扩展其他英雄、服饰、枪械和近战。

## 验收情景

| 情景 | 观察内容 |
|---|---|
| 静止时瞄准绕人物一周 | 枪口方向连续，枪械不倒置，手掌不脱离，身体没有过度扭转 |
| 正上／正下附近小幅左右移动准星 | 主朝向稳定，不在临界位置反复翻面；越过切换范围后能正常转向 |
| 左、右、上、下及斜向瞄准并开火 | 握点稳定，枪口可见，出弹方向一致；尤其不把枪埋入头部 |
| 站立单发与持续开火 | 后坐后能恢复，连续开火能重触发，反馈不累计漂移 |
| 横移、斜移和反向移动时持续射击 | 换脚不断，武器瞄准独立，身体与持握组衔接可信 |
| 开始移动、停止、撞墙 | 步相随真实位移变化，撞墙时不持续原地跑；停止状态稳定 |
| 暂停、失焦、恢复和重开 | 不残留移动或开火输入，不突然跳到错误朝向或动作状态 |
| 游戏参考尺寸与放大视图 | 缩小时轮廓、眼部、围巾与枪口仍清楚；放大时检查重复肢体、配饰跳变及透明边缘 |
