## 已知限制

- 当前v4是完整人物逐帧合并画面，枪械仍烘焙；v3六层关节试验已被用户否定其方法，不能当作当前层级制作已完成。
- 原八帧保留了原姿势中尚未完全解决的步态问题。补帧能补充画面，不能自动证明原关键帧、衣褶、腿部配饰和所有过渡已经自然。
- 透明边缘筛选后可见身体为37／75原生像素，工作规格38／76；预览应使用整数2／1倍，不强行拉满76。
- 活动游戏仍是原静态插画，没有切成未验收像素动作。
- 用户整体视觉、实际手柄与真实WebView2长局尚未通过；不以自动诊断代替。
