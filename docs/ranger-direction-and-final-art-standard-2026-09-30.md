# 巡线者方向握持核对与成品美术标准

日期：2026-09-30。玩家已认可骨架样板的基本动作与节奏，明确指出简单色块距离成品美术很远。此次工作的通过条件分成“骨架方向正确”和“成品角色达到原画水准”；前者不能替代后者。

## 1. 本轮核对与修正

旧持枪源只旋转枪械及手部目标，躯干和头部仍朝前；四方向检查只测跑步第 1 帧。新版 `ranger_directional_pose.py` 以同一源重建站立、移动和射击方向：

- 站立时髋部、躯干与头部朝向瞄准；移动时髋部与腰部共同转向，腰部转角最多 45°。使用连续角度关系，越过正后方不会突然从左扭切成右扭。
- 枪械控制点由躯干带动，双手锁定枪柄和包覆握点，肘部极点随躯干方向旋转。提高枪位并缩短代理枪结构，改正旧低位待机和双手距离过大的问题。
- 侧移、斜后退使用较宽站距和较短步幅，避免把前跑脚路旋转后发生靴子穿插。前向保留原有支撑周期与节奏。**这些方向源尚未按游戏实际移动速度验收**；运行时必须按各动作步长与真实位移推进步相，不能固定时间播放造成滑步。
- 加入仅供结构检查的后坐、枪口上抬、套筒回退与抛壳演示。枪口闪光、代理枪和壳体依然是粗体块，不是成品射击美术，也不代表游戏射速参数。
- 导出时旧动画会重新覆盖手动设置的方向。新版先保存认可的步态采样，再让方向控制器接管导出；每帧渲染后再次核对朝向和握点。八张方向图已确认各不相同。
- 预览改为按固定相机投影的脚底原点放置，提供接地参考网格；不再把每帧人物缩放或裁边位置误当作世界脚底。

这些检查不证明肩部衣物、腰部接缝、手指或面罩形体已经合格。现有刚性部件会呈现明显盒体/拼接外观，背部衣摆尤其简陋。最终网格更换后，当前椭球靴子测试也必须换成适合新网格的检查。

重建命令（`WASTELAND_BLENDER_BIN` 指向本机 Blender）：

```powershell
& $env:WASTELAND_BLENDER_BIN --disable-autoexec --background --factory-startup --python-exit-code 1 --python scripts/blender/build-ranger-directional-sidearm.py
& $env:WASTELAND_BLENDER_BIN --disable-autoexec --background --factory-startup --python-exit-code 1 --python scripts/blender/verify-ranger-directional-sidearm.py
python scripts/qa/build-ranger-direction-review.py
python scripts/qa/make-ranger-lookdev-board.py
```

`--python-exit-code 1` 保证 Python 断言失败时 Blender 返回失败状态。`--stills-only` 只导出快速静止样张，不能生成完整评审页。导出开始时将预览标为重建中，只有 296 帧全部完成且渲染后核对通过才标为完整，避免混用新首帧和旧中间帧。

后向瞄准时，枪械部分被身体遮挡符合视角关系；人物必须真实显示背身，不能为了露出枪而保持正面人物。射击关键帧已检查枪口闪光是否出现在枪口方向，最终还需靠出膛弹体、枪口光和躯干反应确保战斗读图。

## 3. 成品美术的硬标准

主要风格继续对齐现有废土厚涂原画。《死亡细胞》借鉴的是可编辑 3D 源、明确关键姿势、二维逐帧处理和小尺寸的明暗块组织。若后续决定偏像素化，应先做一个孤立动作对照，人工整理像素簇与轮廓；单纯降低分辨率不会变成精细像素美术。

| 部位/系统 | 必须重新制作的内容 | 76px 和放大检查标准 |
|---|---|---|
| 人物比例与体积 | 成人身体比例、真实肩胸骨盆、完整正侧背体积；兜帽可以宽但不能掩盖全部躯干 | 与当前原画并排保持角色身份；侧背身不突然变宽或缩短 |
| 面罩和兜帽 | 镜框厚度、镜片明暗、滤罐/通气孔、固定带、颈部和帽沿形体 | 镜片与口鼻滤罐可辨；不会每个方向都画成正面两眼 |
| 双手和枪械 | 真实手掌/手指、正确包覆与拇指位置；待机和扣扳机手指分开；枪柄、扳机护圈、滑套、准星、枪口与抛壳口独立 | 手与枪不悬空；指节不融成球；手指不挡滑套或枪口；枪位与视线协调 |
| 衣服与换装 | 可变形袖子与裤腿、肩肘膝权重、衣摆厚度及开衩、皮带/胸前挂件/口袋结构 | 接缝和肘膝体积稳定；不是旋转硬圆柱；外套不穿腿 |
| 厚涂材质 | 与原画一致的补丁、缝线、皮革、锈金属、围巾和衣褶；稳定的光源与明暗块 | 76px 保留剪影和材料分区，152px 看得到结构细节；避免噪点淹没人物 |
| 跑动与瞄准 | 受力、腰肩反向、停步收脚、侧移和后退专用姿势、方向过渡 | 脚踩实地面；身体朝向可辨；实际游戏速度下不滑步 |
| 射击表现 | 回弹和恢复、套筒/抛壳、枪口光、衣物和上肢反应；按枪械家族复用 | 关闭闪烁/抖动后仍可读；效果不盖住脸、敌弹或 HUD |
| 输出与整合 | 同一源和光源离线渲染、固定根/两手/枪口投影锚点、分层或必要整身帧、关键帧修画 | 不用逐帧随机生成图片造成服饰漂移；不把源模型装入玩家运行包 |

## 4. 新的精细目标稿

`art/animation/ranger/lookdev/ranger-sidearm-quality-target-v1.png` 是本轮用现有角色原画为身份与材质参考、以骨架为粗略姿势参考生成的单帧目标。RGBA 真透明，已登记为 inactive study，原始提示词和哈希在同目录。原有持枪长枪肖像继续保留；新稿用于补充手枪双手握持和完整服饰细节。

`output/animation/ranger/lookdev/quality-board-76px.png` 和 `quality-board-152px.png` 将当前原画、骨架和目标稿并排。新的单帧目标在实际尺寸更接近当前游戏画风，但**没有对应的精细 3D 网格或整套动作帧**。图中枪械已烘焙，不可直接作为独立换枪身体层。手指、姿态、侧背面一致性仍需正式美术修整。

## 5. 下一批实际交付

1. 以这一完成度重建一名巡线者的精细网格与手绘材质，优先完成头/面罩、胸肩/手、枪械和可变形裤腿；不继续给当前盒体添色块当成品。
2. 在同一精细源完成正面、侧面、背面静止持枪对照，逐件校准握点、头部朝向和衣服遮挡。
3. 先制作一套短跑步与一次射击的成品片段，在 76px 和真实地图背景检查手、脚与关键细节；通过后扩展完整方向组合、停步/受击和装备。
4. 再做图集与实际游戏接入，测默认移动、墙边、暂停、瞄准热切换、手柄和内存。近战刀动作复用手腕挂点，但挥击与伤害窗口仍单独设计。
