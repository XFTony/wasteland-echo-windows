# 生存压力、战地改件与武器扩展执行计划

日期：2026-10-30。用户已认可回声旧城美术，本轮集中改玩法反馈与内容。保留持续计时、自动瞄准射击、随时返回交易站；“尸潮轮数”作为连续生存的45秒进度段，不强制波间休息。

## 已确认的问题与证据

- 原开局生成间隔约1.21秒，敌人上限18，且多数从1280×720视野外进入；击杀速度超过进入速度，前期缺少压力。
- 零散布手枪等增加弹丸后仍使用0度散布，额外弹丸完全重叠，玩家看不到数量变化。
- 特殊武器分支没有完整使用通用机制造成的弹速/击退/弹体/穿透参数，存在卡牌与实际攻击不一致。
- 改件只展示定性文案，没有当前武器的实际前后值；缺少个人改件档案和连续尸潮解锁反馈。

## 调研与适用边界

[Brotato Waves](https://brotato.wiki.spellsandguns.com/Waves)社区资料：基础20波，前九波时长为20/25/30/35/40/45/50/55/60秒；之后多为60秒，第20波90秒。战斗结束进入升级/购物；不是只按整局时间持续加怪。

[Brotato Enemies](https://brotato.wiki.spellsandguns.com/Enemies)：种类和危险等级影响出现时机；普通上限100只，原作超限会移除普通敌人；生命/伤害随波数成长，速度与波数的关系受模式影响。没有取得足够可靠的每波精确出生总量，不能把“100上限”说成第一波实际数量。

[Brotato Weapons](https://brotato.wiki.spellsandguns.com/Weapons)页面标注Patch 1.1.6.3：近战有挥砍/刺击，远程依靠投射物，穿透和弹射是不同机制。采用攻击形态与适用改件分类，不照搬原作单位与六武器同时持有规则。

《元气骑士》社区的[Shotgun Barrage](https://soul-knight.fandom.com/wiki/Shotgun_Barrage)、[Halberd](https://soul-knight.fandom.com/wiki/Halberd)搜索摘录提示霰弹数量增益有武器适用范围，近战可用不同刺击/挥砍形态；正文提取失败，不引用未经核实的精确系数。参考用途是攻击形态、清楚的适配关系和匹配特效，不复制其素材。

## 一、前期压力样板

以下为本项目初始调参，需实战模拟与本人试玩验证，不是竞品数据。先增加数量/进入频率，不叠加提升前期血量和接触伤害。

| 连续时间 | 普通敌上限 | 基础生成间隔 | 目的 |
|---|---:|---:|---|
| 0—20秒 | 28 | 0.58秒 | 尽快形成持续追击，开场额外小组仍从安全距离进入 |
| 20—45秒 | 40 | 0.44秒 | 不再长时间等怪，逼迫移动与捡拾 |
| 45—90秒 | 52 | 0.36秒 | 第一轮结束后逐步形成尸潮 |
| 90—180秒 | 68 | 0.28秒 | 让改件构筑与交易选择发挥作用 |
| 180—300秒 | 86 | 0.22秒 | 提高多方向包围与精英混合压力 |
| 300秒后 | 最多104 | 0.18秒逐步降至0.11秒 | 保持现有实体上限和无限成长边界 |

测试分别记录生成总量、同时存活、进入视野数量、击杀、玩家受伤和首次升级时间；无敌压力夹具只证明稳定性，正常生命脚本只作比较，不替代人类难度判断。

## 二、改件生效与解锁

先对34个已有改件核对属性、实际射击/命中、机制触发和武器适用性。多弹轨迹至少保持可见分离；射线、爆破、弹射与近战使用明确的规则，不把不适用的增益塞进候选池。

新增8个改件：弱点增幅（暴伤）、猎获修复（击败回血）、格斗节拍（近战攻速/伤害）、锯盘导流（弹射）、寒霜延时（减速）、爆裂装药（范围攻击）、战场步频（走位/攻速）、散射收束（散布/射程）。完成第1/2/3/4轮逐步加入候选池；最高记录兼容已有bestTime，避免为解锁另造一份冲突存档。

个人“战地改件档案”展示全部改件、作用、适用攻击、解锁轮数与状态。局内暂停可查看已装配等级和当前实际属性；升级卡给出本次前后值，达到上限或对当前武器无效的选项不会误导。

## 顺序与验收

1. 冻结旧基线与建立分支，保存调研/设计。
2. 修复真实增益链并增加行为核验，逐一记录保留、修复和不适用项。
3. 调整连续生成曲线，接通45秒尸潮进度与基于历史记录的改件解锁。
4. 接入八改件及个人/局内查看、前后值预览。
5. 接入四武器及完整美术/声音/交易/规则，检查枪口、范围、击退、墙体、池复用与性能。
6. 区分原版未变规则的回归与本轮有意更改，不为追求旧JS数值完全一致而撤回新玩法；新规则用独立可解释的行为测试。
7. 实窗截图、自动战斗比较、存档往返、独立包自检后提交备份；保持内部版本，不提前发布正式标签。

## 2026-10-31执行结果与下一步

主要实现已完成：441项本轮专项通过，42项实际选择均改变原生属性/机制/资源，12件远程武器的八方向多弹核验通过；四件新武器及八个改件已有独立视觉与反馈。档案、暂停属性、卡片前后值、尸潮进度与持久解锁均已接入。完整逐项记录和原版回归的有意变化见[验收记录](../qa/survival-builds-validation.md)。

首张地图的正常构筑固定走位样本可完成60秒，剩余37.16/116生命；站桩40.25秒死亡。它说明前期密度已改变，不代表难度已合适。完成打包和备份后，后续按以下顺序推进，不重复制作已认可地图美术或角色动作：

| 优先级 | 下一步 | 方法与通过条件 |
|---|---|---|
| P0 | 本人确认第一图首分钟压力 | 默认手枪实际游玩；记录第一次升级、受伤与被包围时刻，判断20—45秒是否过陡；先调生成节奏，不同时改怪物伤害 |
| P1 | 四件新武器同场比较 | 同地图/相近构筑比较刺击宽容、斧前摇、弩穿透和寒霜换位收益；修真实体验后再扩武器数量 |
| P1 | 构筑与交易的中期价值 | 正常生命多seed、5—10分钟，分别记录改件选择/币与升级消耗/塔台存活；防止只堆伤害或多弹成为唯一答案 |
| P1 | 其他两图与低配验证 | 首图节奏确认后再调地图差异；真实窗口测帧时间、内存和加载，不以headless模拟代替设备结论 |
| P2 | 专属进化与更多内容 | 本轮四武器先使用通用精通，只有现有类别形成稳定差异后再设计专属蓝图，避免重复扩量 |
