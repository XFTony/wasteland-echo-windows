# 卡牌对齐、语言选择与安全清理

日期：2026-10-31。已认可画风基线：8ebdf50。范围：修正卡牌图案定位与焦点残线；澄清语言与分支；按可恢复清单清理历史废弃项，不更换画风和玩法。

## 卡牌问题与修正

- 六种异形卡框的插画窗口位置不同，旧代码共用0.285高度与近似横坐标，导致火力、机动等卡面中的可见图案偏移。现将六种窗口和标题纸签分别保存成原生Resource，按256×384源卡面测量后缩放。
- 插图按实际Alpha内容边界等比居中，不让透明留白影响视觉位置；保留原稿与运行图，不改动已认可图片内容。
- 下方金色横线和侧箭头来自旧通用按钮focus_ink。升级卡移除该装饰，保留抬升/轻微变亮，并将选择标识放在卡内编号纸签上。减少动态效果时也能识别焦点。
- 拾荒增益简化重复说明，预览明确收益倍率与小数累计；断行不让闭合标点独占一行，不改变任何属性计算。
- 16个实际鼠标悬停（4卡×4分辨率）与键盘焦点已核验，下方亮金残线最长连续像素为0；145项布局/实际图像边界检查通过。实体手柄和系统DPI仍按设备矩阵验收。

## 当前语言与GitHub统计

GitHub官方接口核验：默认分支main的树为a8eff8a，尚无godot/project.godot；最新原生迭代位于codex分支。默认分支语言字节数：JavaScript783,084、PowerShell15,756、Python5,075、CSS1,185、HTML847、Rust683，JavaScript约97.08%。这不是当前原生运行包的语言组成。

清理前开发分支按扩展名近似统计：GDScript93文件/637,662字节，JS180文件/1,172,985字节，MJS46文件/355,165字节、Python53文件/303,793字节；包含旧版、测试、工具与实验，不能等同于游戏运行依赖。当前godot目录没有C#脚本或csproj，原生包不执行旧JavaScript。

**建议继续以带静态类型的GDScript作为唯一游戏逻辑主语言。**它与当前场景、Resource、Control、输入、存档和回归已经贯通；Node/Python/PowerShell保留在构建、素材生产、迁移参考和验证层。工具链使用多种语言不要求游戏再引入一种运行语言。

C#确实是Godot官方支持的完整开发语言，不是记错。官方资料要求使用.NET版编辑器和相应工具链；项目还需程序集构建，某些引擎API调用存在跨语言封送成本。它对复杂计算/既有.NET库有价值，但不能仅根据GitHub语言条证明重写会更快。本项目没有性能剖析证据支持现在整体改写C#。将来若导航或碰撞计算成为已测热点，再用局部对照基准决定C#或GDExtension。

不为改变语言统计而删除仍服务于迁移回归的src/web/test，不修改默认分支或自动合并main。原生主线集成应走独立PR与检查，不把语言选择、代码清理、主分支切换混成一次不可追踪的大改。
