# 荒原回响：废土电台与行动手册界面

日期：2026-10-28。基线：`d0a7b49`。本轮范围为启动、菜单、共享控件、页面布局和相应验收，不改变战斗数值与已认可角色。

## 设计目标

以旧电台、营地与行动手册建立识别：像素营地和桌面环境、墨印回声标记、旧铜机械按键、纸签与布面分区。克制大面积亮边，保留中文扫读与键鼠／手柄焦点。

| 顺序 | 实施 | 通过条件 |
|---|---|---|
| 1 | 两幅复用环境、项目标记与材质规则 | 主角与背景同属紧凑像素语言；图片不包含交互文字 |
| 2 | 实际时间驱动的短启动动画 | 键鼠／手柄可跳过；跳过不误触菜单；弱动态／缺图不会卡住 |
| 3 | 共用按钮、纸签、布面和焦点 | 按下／悬停／键盘焦点可辨，正文对比度保持 |
| 4 | 主菜单与部署、商店、行装等页面 | 信息主次明确，540p及720p不重叠，现有入口齐全 |
| 5 | 升级、暂停、结算与HUD协调 | 实战危险信息仍醒目；视觉变化不改判定 |
| 6 | 多分辨率、输入、启动及实际构建复验 | 程序回归、截图与独立Windows内部试玩包；未测设备如实记录 |

启动使用程序动画叠加背景，复用主菜单资产；不用视频、不伪造加载百分比、不以装饰动画阻止进入游戏。优先使用系统中文正文，像素字仅用于品牌标题。
