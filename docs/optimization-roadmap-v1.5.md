## 2. 当前实测结论

- 191/191 项 Node 测试通过；
- 正常生命 180 秒六策略矩阵 3/6 通关；默认、随机升级、无磁吸通关，失败局仍输出承伤来源；
- 600 秒压力局保持运行，2015 击败、3 波 Boss，RSS 峰值约 125.98 MiB；该增长需在下一轮继续观察；
- 最新 Edge 快速场景最低 1% low 118.34 FPS，0 页面错误；此前完整 18 场景最低 72.46 FPS；
- 商店/背包/档案/机制卡/Boss/结算 7 张真实 Edge 截图已复核，瞬时横幅遮挡 Boss HUD 的验收脚本问题已修复；
- 三体型流场改变了敌群路径与难度，后续平衡必须以新矩阵重新冻结。

## 4. 暂缓

- 大量新武器/皮肤：先完成机制化构筑；
- Steam SDK、云存档和联机：不属于当前纵切；
- 删除 `art` 源图或历史截图：会破坏许可与视觉回归证据；
- 商业签名与 license 决策：需要用户提供证书预算和发行方式。
