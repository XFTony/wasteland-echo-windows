# 自动战斗方向与七把枪适配记录

日期：2026-10-27。用户确定：人物视觉、转向与持握参考《元气骑士》，操控方向参考《土豆兄弟》，玩家主要负责移动，人物自动找敌人与射击。

## 玩法调研

直接来源：[Brotato官方Steam页面](https://store.steampowered.com/app/1942280/Brotato/?l=schinese)，开发者／发行商Blobfish；复核日期2026-10-27。辅助官方展示：[Godot项目展示](https://godotengine.org/showcase/brotato/)。

官方说明支持以下核心结构：

- 武器默认自动射击，提供可选手动瞄准；常规体验无需持续操作射击方向。
- 一名角色可以同时携带最多六把武器，搭配角色特性和道具形成构筑。
- 单次敌袭持续约20–90秒；主要战斗选择集中于走位、规避威胁和拾取路线。
- 击杀与拾取获得经验，波次间购买道具，形成“战斗→成长／商店→下一波”的节奏。
- 官方还提供敌人生命、伤害、速度等难度选项。具体平台和版本的选项可能有差异。

官方商店文案没有完整公开目标选择和锁定切换算法。因此，下文的范围检查、近距离稳定锁定、遮挡排除和枪口补偿是本项目实现规则，不宣称测得原版源码中的全部细节。

## 本轮已经实现的范围

1. 主游戏新存档默认`autoAim=true`、`autoFire=true`；现有存档的明确手动偏好保留。旧档如自动开火为关，可在设置中开启。HUD、设置说明和首次教学对应更新。
2. 新[七枪自动战斗样板](../art/characters/ranger/compact-arsenal-v2/review.html)默认只需WASD／方向键移动，不需要点鼠标或按射击键，鼠标不会覆盖自动瞄准。
3. 样板会在当前枪械的有效锁定范围内选择存活、可攻击的敌人；死亡、失活、超出范围和被箱体阻挡的对象不可触发开火。接近距离时保留当前锁定，减少左右来回跳转。
4. 目标在枪口以内时仍能命中；长枪的初始碰撞检查覆盖持握组到枪口的短路径，防止贴身死区和越过薄墙出生。枪械、双手、后坐、枪焰和出弹同源。
5. 样板适配现有七把枪，保留内容ID与基础伤害、射速、射程、弹数、散布、弹速、寿命及穿透参数。完整专属机制、升级和关卡规则仍由主游戏执行。

| 枪械 | 形象与持握 | 基础射击表现 |
|---|---|---|
| 废料手枪 | 复用已有紧凑双手持握图 | 单发、中等节奏 |
| 蜂群冲锋枪 | 绿色短机匣、弯弹匣、短托；手靠近后握把与前护木 | 快速连射、小后坐 |
| 破门霰弹枪 | 橙棕泵动护木、短实心托；托枪手位于泵动护木 | 六发扇形散射、较强后坐 |
| 针刺步枪 | 细长枪管、上方瞄具、分离握点 | 高速单发、贯穿 |
| 锈痕左轮 | 大弹巢、短粗枪管、紧凑双手握法 | 较慢单发、明显后坐 |
| 余烬卡宾枪 | 橙色机匣标记、弯弹匣、前后分开的手 | 中速连射 |
| 荒雷线圈炮 | 铜线圈、青色核心、较厚枪体和前托手 | 慢速重弹、贯穿、青色开火反馈 |

## 美术与遮挡处理

六把新枪的原画由内置ImageGen分别生成，废料手枪复用上一版。新图按统一原生像素规格和受控色板导入，尺寸不是对同一图简单拉伸。每把枪独立记录握点、枪口、后坐幅度和上向挂点。

正面枪械不再遮住人物面罩：枪组绘制后，头部的相同不透明像素覆盖枪托，前方枪身、手与枪口保持可读。上向持枪同时检查最大后坐位置，避免静止枪口可见而开火时埋入头部。

六张源图、最终提示词、导入参数、PNG与可编辑源均保留。步枪的一次图像请求被工具安全检查拦截；随后改为明确的虚构游戏道具描述，仅引用已有像素组件风格，已成功生成。源记录使用最后一次实际提示词。

## 与完整《土豆兄弟》玩法的区别及后续顺序

本轮落实自动战斗操作和七枪持握。现有主游戏仍使用自己的章节、三分钟模式、升级与经济规则；没有把“七种可选枪”宣称为“同时装备七把枪”。

后续建议先把当前主角与枪械表现接入第一章真实战斗，检查自动选敌、敌群压迫和升级效果。之后再做一张地图的短波次／波次间购物试验，验证战斗与构筑节奏。多武器同时独立寻敌是更后一步，需要重新设计槽位、手部遮挡、属性合成和资源预算，不能只叠加多个持枪图。
