## 部分成立，分阶段处理

| 诊断项 | 处理判断 |
|---|---|
| 全拆 GameModel | 目标正确，但一次性拆五个系统风险过高；按 EnemyBrain → CombatSim → SpawnSystem → RunSession → MetaFacade 顺序推进 |
| 寻路动态障碍/撤离流场 | 三档 clearance、薄障碍和连通性已完成；动态 dirty 与撤离目标流场留在下一批 |
| 内容按域拆分 | `config.js` 偏大属实，但玩法机制仍在变化；先稳定 ContentPack 契约再机械拆文件 |
| 自动瞄准默认开 | 是产品定位选择，不是代码错误；保留休闲向默认开，并在设置/发布说明明确，可随时关闭 |
| 机制化升级/BossDefinition/Meta | 是产品最大缺口，但依赖继续拆分和矩阵工具；列为 v1.5 后续 P0 |
| 音频总线/振荡器池 | 有价值但当前没有爆音或并发失败证据，排在玩法核心后 |
