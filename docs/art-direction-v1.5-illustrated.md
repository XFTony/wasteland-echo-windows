## 下一批工作，按阻断程度排序

1. **P0：补足武器与服饰组合。** 目前只有起始手枪使用独立插画；其他六把武器和两件非默认服饰仍会回退旧像素人物。为每把武器定义稳定视觉 ID、独立透明图及正确的持枪锚点。服饰与英雄身体组合采用分层覆盖，不能用错误武器立绘冒充当前装备。
2. **P0：补齐地图对象。** 地表已分化，但建筑、障碍、路轨和场景道具仍是明显的平面几何图。先完成第一章地标和碰撞对象图集，确保视觉边界不误导碰撞；再把复用部件拓展至另外两图。检查地表平铺接缝和固定视野下的重复花纹。
3. **P0：统一商店、背包、升级与结算。** 商店武器、护具和升级图标仍是旧像素图；背包网格留白大，选中物品说明偏小。按信息优先级调整布局，图标更新后复核 960×540 与 720p 正文、手柄焦点和鼠标点击区。
4. **P1：角色动作和打击反馈。** 当前身体采用上下浮动和水平镜像，尚无完整移动、受击、倒地和方向动作。第一章先把巡线者、漂游者和 Boss 的动作状态定稿，再评估复用成本。敌弹、枪口火光和危险预警需与插画画风统一并保留色盲可辨的形状差。
5. **P1：运行时资源边界。** 按地图和菜单页释放不用的图；记录 WebView2 解码内存、频繁切页和 30 分钟长局趋势。当前快速 Edge 帧率只作早期信号。
6. **P1：完整验收。** 六菜单、背包、商店、设置、升级、暂停、胜负结算及三地图分别检查 960×540、720p、1080p、1440p 和 Windows 显示缩放；完成键鼠、实体手柄七局矩阵，检查存档兼容和安装包。全部通过后再考虑 `v1.5.0-alpha.2` 及公开预览。
