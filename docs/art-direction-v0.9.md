# 《荒原回响》v0.9 美术方向与界面规范

## 1. 设计目标

本版本把原先偏青色霓虹、透明面板的界面重构为“废土军械箱”视觉：煤灰背景、旧木框架、氧化铁、黄铜铆钉、蜡帆布和皮革标签。界面应像营地中真实可触摸、可拆装的物件，而不是悬浮玻璃屏。

设计强度：`DESIGN_VARIANCE 7 / MOTION 4 / VISUAL_DENSITY 7`。画面允许不完全对称和较高信息密度，但主要动作、危险和数值必须一眼可辨。

## 2. 参考结论与边界

- 《我的世界》背包只借鉴信息结构：人物预览、人物周围的四个护甲槽、右侧规则网格和悬停说明；不复制纹理、图标或像素人物。
- 《炉石传说》只借鉴“界面是一件真实物体”的原则：厚边、材质差、硬阴影、铆钉、压下反馈和卡牌层级；不复制卡框、宝石、标识或具体构图。
- 《元气骑士》只借鉴低饱和环境、清晰角色轮廓和少量高对比战斗信号；不复制角色、武器或场景素材。

## 4. 行装与背包

- 左侧是实体衣装柜：人物位于中央凹槽，头盔、身甲、腿甲、靴子沿左侧纵向排列，主武器和行动服位于右侧。
- 右侧固定为 5×4 物品格；物品格本身是铁框与深色内衬，选中状态使用硬边和材质抬升，不使用发光。
- 底部“生存参数”显示生命、护甲、移动、增伤，并补充射速、拾取和锁定倍率。
- 人物头部、眼睛、头饰与头盔根据鼠标相对人物中心小幅偏移，最大约 2～3 个逻辑像素；切换手柄或鼠标离开窗口后平滑回正。
- 点击背包物品执行装备，点击人体上已穿戴槽位执行卸下；所有变更必须经过动作路由和核心装备模块。

## 5. 人物与护具组合

人物绘制顺序固定为：阴影 → 腿 → 靴子 → 腿甲 → 外套/背包 → 躯干 → 身甲 → 头部 → 英雄/服饰饰件 → 头盔 → 手臂/武器。每件护具在内容数据中拥有唯一 `visualId`，背包图标、商店图标和人物外形共同使用该 ID。

当前六件护具保留稳定内容 ID；旧工具和挂件被重新解释为可穿戴头盔或腿挂，以便旧存档升级后仍可使用。

## 6. 数值与兼容规则

- 四个合法槽位只有 `helmet / chest / legs / boots`。
- `calculateLoadoutStats` 是背包预览与战斗开局的唯一属性公式；渲染组件不得自行计算另一套结果。
- schema v6 将旧 `armor` 映射到 `chest`，将 `magnet_coil / signal_charm` 映射到 `helmet`，将 `ammo_rig` 映射到 `legs`。
- 两件旧物竞争同一槽位时只决定当前穿戴者，另一件仍保留在 `ownedEquipment` 中。
- 新增护具时必须同时提供合法槽位、唯一 `visualId`、属性、背包/商店图标表现和人物部位表现，并更新自动测试。
